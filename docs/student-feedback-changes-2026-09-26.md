# Changes following student feedback

Reviewed seven responses in the supplied feedback workbook. Ratings ranged from
3 to 5 (average 4.0/5); the small sample describes these testers, not the whole class.

| Feedback | Response in this update |
| --- | --- |
| Citations reach the correct page, but the exact paragraph is hard to find. | Added a visible **Cited passage** panel quoting matched source text above the selected page, while retaining highlights on the original. |
| Erlitou and Yinxu are too difficult to distinguish on a China outline. | Replaced those two maps with a shared regional zoom, Yellow River, provincial boundaries, coordinate grid, scale and China locator inset. Locations remain approximate; modern geography is labelled. |
| Flashcards feel too easy for some students and too difficult for others. | Added **Recall / Explain / Apply-discuss** levels. Harder levels ask for reasoning supported by the selected slides, not additional reading knowledge. |
| Students want to write complete answers rather than fill blanks. | Added an optional written-response box to flashcards before model-answer reveal. General practice already uses open image, map and concise-answer questions. |
| Practice repeats and omits parts of the slides. | Added eight slide-backed questions (53 active questions total), including Tikal and Tel-Abada. New sets prioritise previously unattempted questions across sessions. |
| Broad concepts need a short definition and fuller explanation. | Tutor instructions now request a brief evidence-supported definition before examples. Search also includes short slide captions previously omitted, improving site and concept coverage. |
| A question came from a crossed-out part of a reading. | Verified that active practice and flashcard sources remain lecture-slide-only. Vitrification from the reading is absent from the active question bank. Readings remain available for chatbot Q&A. |

## Checks and limits

The original feedback workbook is unchanged and no respondent data is published.
Every new question has slide evidence and a marking rubric. Source matching,
question selection and grading remain distinct: a valid citation does not by
itself prove every AI interpretation is correct. Student difficulty preferences
are not an official quiz specification. The word “Apply” does not mean confirmed
exam difficulty.

Short caption coverage improves retrieval but does not promise recognition of
every unlabeled site in an image. The detailed maps use modern geographic
reference data, not reconstructed ancient river courses or political boundaries.
Reading annotations have not been interpreted as an authoritative syllabus;
practice continues to exclude readings entirely, following the professor's
previous direction.
